# CV-Webapplication — Zebra Crossing Violation Detection
 
ระบบตรวจจับรถยนต์ที่จอดขวางทางม้าลายด้วย AI (Computer Vision) พัฒนาต่อยอดจากโปรเจกต์ตรวจจับคนข้ามถนน โดยใช้โมเดล YOLO ตรวจจับยานพาหนะที่จอดขวางทางม้าลายแบบอัตโนมัติ
 
## Tech Stack
 
- **AI Model:** YOLOv8 / YOLO26 (Object Detection)
- **Backend:** FastAPI
- **Frontend:** Next.js
- **Database:** PostgreSQL
- **Deployment:** Docker, Docker Compose, AWS EC2
## วิธีรัน
 
```bash
docker-compose up
```
